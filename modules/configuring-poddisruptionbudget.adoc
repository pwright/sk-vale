= PodDisruptionBudget configuration

[role="_abstract"]
The operator creates a PodDisruptionBudget for the {registry} application and for the web console when that component can have more than one pod: with autoscaling enabled, a `maxReplicas` above one (it defaults to `minReplicas`); otherwise, more than one replica. A budget for a single pod would allow no voluntary disruption, and block node drains. To manage PodDisruptionBudget manually, disable the operator-managed PodDisruptionBudget.

[source,yaml]
----
spec:
  app:
    podDisruptionBudget:
      enabled: false
  ui:
    podDisruptionBudget:
      enabled: false
----
