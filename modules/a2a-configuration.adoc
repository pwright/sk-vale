= A2A configuration properties

[role="_abstract"]
You can control A2A features by using the following configuration properties.

.A2A configuration properties
[cols="2,1,3",options="header"]
|===
|Property |Default |Description

|`apicurio.a2a.enabled`
|`false`
|Enable or disable A2A protocol support

|`apicurio.a2a.agent.name`
|`Apicurio Registry`
|Name of the registry as an A2A agent

|`apicurio.a2a.agent.description`
|`API and Schema Registry with A2A Agent support`
|Description of the registry agent

|`apicurio.a2a.agent.version`
|_app version_
|Agent version (defaults to application version)

|`apicurio.a2a.agent.url`
|_registry base URL_
|URL reported in the Agent Card `supportedInterfaces` entry. Defaults to the base URL of the registry.

|`apicurio.a2a.agent.provider.organization`
|`Apicurio`
|Provider organization name

|`apicurio.a2a.agent.provider.url`
|`https://www.apicur.io`
|Provider organization URL

|`apicurio.a2a.agent.capabilities.streaming`
|`false`
|Whether streaming is supported

|`apicurio.a2a.agent.capabilities.push-notifications`
|`false`
|Whether push notifications are supported

|`apicurio.a2a.agent.protocol-version`
|`1.0`
|A2A protocol version reported in the Agent Card and in its supported interfaces

|`apicurio.a2a.agent.documentation-url`
|_not set_
|URL of the registry agent documentation, reported as `documentationUrl` when set

|`apicurio.a2a.agent.icon-url`
|_not set_
|URL of the registry agent icon, reported as `iconUrl` when set

|`apicurio.a2a.agent.auth.api-key.enabled`
|`false`
|Advertise API key authentication with the `X-API-Key` header in the Agent Card security schemes
|===
