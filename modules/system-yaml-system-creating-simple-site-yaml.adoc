= Create a simple site on local systems using YAML

[role="_abstract"]
You can use YAML to create and manage Skupper sites.

.Prerequisites

* The `skupper` CLI is installed.

.Procedure

. Create a site CR YAML file named `my-site.yaml` in an empty directory, for example, `local`:
+
[source,yaml]
----
apiVersion: skupper.io/v2alpha1
kind: Site
metadata:
  name: my-site
----
+
This YAML creates a site named `my-site` in the `default` namespace.

. Create the site:
+
[source,bash]
----
skupper system apply -f my-site.yaml
skupper system start
----
+
The `apply` command stages the custom resources from the YAML file into `~/.local/share/skupper/namespaces/<namespace>/input/resources/`.
The `start` command processes the staged resources and starts the site.
Typically, you apply all resources you require for a site before running `skupper system start`.
+
*Optional:* Enable the Dynamic System Controller to automatically process YAML resources:
+
[source,bash]
----
export SKUPPER_SYSTEM_RELOAD_TYPE=auto
skupper system install
----
+
With this feature enabled, you can create sites, links, connectors and listeners without needing a system reload to apply your configuration.

. Check the status of the site:
+
[source,bash]
----
skupper site status
----
+
You might need to issue the command multiple times before the site is ready:
+
[source,text]
----
NAME    STATUS  MESSAGE
default Ready   OK
----
+
You can now link this site to another site to create an application network.
