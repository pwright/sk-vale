= Automatic group creation

[role="_abstract"]
You can require clients to create a group before registering its first artifact by disabling automatic group creation.

Default behavior::
With SQL or KafkaSQL storage, `apicurio.storage.enable-automatic-group-creation` defaults to `true`.
Registering an artifact in a named group that does not exist creates the group automatically.
The new group uses the artifact owner's identity as its owner.

Explicit group creation::
With `apicurio.storage.enable-automatic-group-creation=false`, registering an artifact in a missing named group fails with a group-not-found error.
Clients must first create the group, for example, with `POST /apis/registry/v3/groups`.
Existing groups and the built-in `default` group remain available.

.Example: Requiring explicit group creation
[source,properties]
----
apicurio.storage.enable-automatic-group-creation=false
----

The equivalent environment variable is `APICURIO_STORAGE_ENABLE_AUTOMATIC_GROUP_CREATION=false`.
The setting takes effect when you restart the server.
