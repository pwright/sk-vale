= {registry} content rule precedence

[role="_abstract"]
When you add or update an artifact, {registry} applies rules to check the validity, compatibility, or integrity of the artifact content. For each rule type, configured artifact-specific rules override the equivalent configured group-specific rules, which override the equivalent configured global rules. The following table shows this for artifact-specific and global rules; a group-specific rule takes the place of the global rule for the artifacts in its group.
