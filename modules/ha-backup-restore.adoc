= Backup and restore procedures

[role="_abstract"]
Regular backups are essential for disaster recovery and data protection.

{registry} supports backup and restore for both SQL database storage and KafkaSQL storage. {registry} also
exposes a health endpoint (`/health/ready`) and a metrics endpoint (`/metrics`) on the management port (9000),
which you can use to monitor deployment health during backup and restore operations.
