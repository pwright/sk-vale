= Importing tools from a running MCP server

[role="_abstract"]
Instead of writing `MCP_TOOL` artifacts by hand, you can import the tools of a running MCP server, and import them again when the server changes. The same compatibility rules apply, so an incompatible tool change is rejected on import.

NOTE: Importing tools from a running MCP server is planned for {registry} 3.4 and is not available in released versions. For the planned behavior, see xref:getting-started/assembly-mcp-tool-features.adoc[MCP tool definition features].
