= Multi-agent workflow example

[role="_abstract"]
You can chain context across multiple agents in a pipeline: each agent's output becomes part of the next agent's input. The `agent-registry` example in the {registry} repository runs such a pipeline with Quarkus LangChain4j applications:

.Briefing pipeline in the agent-registry example
[cols="1,3,3",options="header"]
|===
|Step
|Input
|Output

|1. Weather tool (MCP)
|A city
|Fictional weather data

|2. Summarizer agent (A2A)
|The weather data
|A short factual paragraph

|3. Translator agent (A2A)
|The summary
|The summary in French
|===

The orchestrator does not know the agents' URLs: the summarizer and translator publish their Agent Cards to {registry} when they start, and the orchestrator discovers them, and the MCP server, by role.

ifndef::service-registry-downstream[]
To run the example locally, clone the {registry} repository and follow its guide:

.Example commands
[source,bash]
----
cd examples/agent-registry
docker compose up -d
./demo.sh
----

The orchestrator's dashboard is available at `localhost:11020`.
endif::[]
