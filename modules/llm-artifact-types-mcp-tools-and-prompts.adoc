= MCP tools and prompts

[role="_abstract"]
The MCP Server exposes the following tools and prompts for working with prompt templates through the MCP protocol.

.MCP tools
[%header,cols="2,4"]
|===
|Tool
|Description

|`list_mcp_prompts`
|List all MCP-enabled prompt templates in the registry

|`get_mcp_prompt`
|Get and render an MCP-enabled prompt with arguments

|`render_prompt_template`
|Render any prompt template (MCP-enabled or not)
|===

.MCP prompts
[%header,cols="2,4"]
|===
|Prompt
|Description

|`render_registry_prompt`
|Interactive prompt for rendering templates from the registry
|===
