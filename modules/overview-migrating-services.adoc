= Expose services

[role="_abstract"]
These examples show how service-exposure commands changed between {skupper_name} v1 and {skupper_name} v2.

[source,bash]
----
contextA> skupper expose deployment/backend --port 8080
----

[source,bash]
----
contextA> skupper connector create backend 8080
contextB> skupper listener create backend 8080
----

The new _routing-key_ option gives you more control over how services are defined, for example to expose the service as `backend2` in contextB:

[source,bash]
----
contextB> skupper listener create backend2 8080 --routing-key backend
----
