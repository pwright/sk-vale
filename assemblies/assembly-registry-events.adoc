= {registry} change events and the outbox pattern

[role="_abstract"]
{registry} emits change events for artifact, version, group, rule, and contract operations.
You can consume these events to audit changes and automate workflows in external systems.

This chapter explains the event system architecture, available event types, and how to configure event delivery for your storage variant.
