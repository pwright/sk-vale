= {registry} change events and the outbox pattern

[role="_abstract"]
{registry} emits change events whenever artifacts, versions, groups, or rules are created, updated, or deleted. These events enable integration with external systems for auditing, automation, and event-driven workflows.

This chapter explains the event system architecture, available event types, and how to configure event delivery for your storage variant.
