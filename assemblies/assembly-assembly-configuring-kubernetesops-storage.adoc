= Configuring {registry} with KubernetesOps storage

[role="_abstract"]
Configure {registry} to use Kubernetes ConfigMaps as the data source for registry artifacts. KubernetesOps storage enables Kubernetes-native management of schemas and APIs using standard tools like `kubectl`, ArgoCD, or Flux.

== Prerequisites

* You have installed {registry} on Kubernetes or OpenShift.
* You have access to create ConfigMaps in your cluster. Deployments without the {operator} also require access to create RBAC resources.
