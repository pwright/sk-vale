= Configuring {registry} security options

[role="_abstract"]
You can configure security options for {registry}, including authentication in {keycloak}, Microsoft Azure Active Directory, or Dex, proxy header and Kubernetes-native authentication, and role-based authorization.

NOTE: For a list of all available configuration options, see {registry-config-reference}.
